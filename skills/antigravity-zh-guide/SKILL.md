# Antigravity 中文使用与功能参考指南 (非官方社区整理)

> **版本与测试说明**：本文档基于 Antigravity 2.0 公开特性与实际测试环境整理维护（更新验证日期：2026 年 8 月）。功能与命令可能随宿主软件后续版本更新而变动，请以实际版本为准。

## 一、 核心交互界面与布局概述

Antigravity 提供了以智能体（Agent）为核心的协作开发体验，包含基于编辑器的集成环境与桌面端协作窗口：

### 1. 侧边导航 (Navigation)
- **新建对话 (New Conversation)**: 开启新的智能体任务会话。
- **项目管理 (Projects)**: 切换或打开不同的代码仓库与工作区。
- **计划任务 (Scheduled Tasks)**: 查看和管理一次性延迟或周期性定时任务。
- **自定义扩展 (Customizations)**: 查看当前工作区与全局加载的技能 (Skills)、规则 (Rules)、插件 (Plugins) 和 MCP 服务器。
- **设置 (Settings)**: 查看或调整模型选择、权限策略及系统常规设置。

### 2. 对话与命令交互区 (Chat Area)
- **斜杠命令 (Slash Commands)**: 输入 `/` 唤起预置的工作流快捷指令。
- **上下文引用 (@ Mentions)**: 输入 `@` 引用工作区文件、会话记录或代码上下文。
- **多模态分析**: 支持将截图、设计草图或文档拖入对话框供智能体分析。

### 3. 辅助面板 (Auxiliary Panes)
- **子代理 (Subagents)**: 查看后台并行执行专项任务的子代理状态。
- **后台任务 (Background Tasks)**: 查看后台构建、测试或脚本执行状态。
- **产物文档 (Artifacts)**: 查看智能体生成的实施计划 (`implementation_plan.md`) 或完成回顾 (`walkthrough.md`)。
- **代码变动 (Files Changed / Diff)**: 审查智能体对文件所做的代码修改。
- **终端控制台 (Terminals)**: 监控终端命令的执行与输出。

## 二、 常用斜杠命令示例 (Slash Commands Reference)

*以下为当前版本支持的常用斜杠命令说明（仅供参考）：*

| 斜杠命令 | 功能说明与适用场景 |
| :--- | :--- |
| `/goal` | 适用于长周期、多步骤的大型任务，智能体将持续推进直到完成目标。 |
| `/grill-me` | 在编写代码前，通过互动问答深入推敲架构设计与技术方案，排查潜在盲点。 |
| `/browser` | 启动受控浏览器进行网页浏览、检索与前端端到端测试。 |
| `/schedule` | 设置一次性提醒或周期性定时任务。 |
| `/learn` | 当纠正了智能体的行为或完成复杂配置后，让智能体持久化记忆此模式。 |
| `/teamwork-preview`| 启动多智能体协作流程，分工处理较大型项目需求。 |

## 三、 常用键盘快捷键示例 (Keybindings Reference)

*注：快捷键可在宿主编辑器按键绑定中按个人偏好自定义。*

| 快捷键 (Windows/Linux) | 快捷键 (macOS) | 功能 |
| :--- | :--- | :--- |
| `Ctrl + I` | `Cmd + I` | **行内透视/编辑 (Inline Edit)**：呼出代码重构与修改建议 |
| `Tab` | `Tab` | **智能补全**：接受当前代码补全建议 |
| `Ctrl + Shift + N` | `Cmd + Shift + N` | **新建窗口**：打开新的工作窗口 |
| `Esc` | `Esc` | 取消建议或关闭当前弹出浮层 |

## 四、 安全策略与权限控制说明

在 `智能体设置 (Agent Settings)` 中，用户可根据项目信任程度自由选择安全级别：
- **安全策略预设 (Security Preset)**:
  - `默认模式 (Default)`：对所有终端命令及工作目录之外的文件访问均需用户手动审核确认（**推荐普通项目使用**）。
  - `整机访问模式 (Full machine)`：所有终端命令需要确认，智能体可访问本机文件。
  - `极速模式 (Turbo mode)`：关闭人工确认环节，以最大化速度执行自动化迭代（建议仅在隔离的测试环境中开启）。
  - `自定义模式 (Custom)`：手动配置各个工具与终端命令的细粒度白名单。
