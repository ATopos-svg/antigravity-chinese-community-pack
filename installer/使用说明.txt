========================================================================
   Google Antigravity（反重力）社区全平台深度汉化包 (v2.12.2)
   支持操作系统：Windows / macOS (Intel & Apple Silicon) / Linux
========================================================================

【压缩包文件清单】
  ├── app.asar.chinese               -> 核心汉化资源包 (全平台通用，基于官方 2.12.2 深度适配)
  ├── 一键安装汉化.bat                -> [Windows] 一键自动安装与退出启动
  ├── 一键恢复官方英文.bat            -> [Windows] 一键秒级还原官方英文
  ├── 一键安装汉化-macOS.command      -> [macOS] 双击一键安装 (内置安全签名去隔离)
  ├── 一键恢复官方英文-macOS.command  -> [macOS] 双击一键秒级还原官方英文
  ├── 一键安装汉化-Linux.sh          -> [Linux] 终端一键安装脚本
  ├── 一键恢复官方英文-Linux.sh      -> [Linux] 终端一键秒级还原脚本
  └── 使用说明.txt                   -> 本文件

【极速安装指南】
1. Windows 用户：
   解压本压缩包全部文件到任意文件夹，鼠标双击运行《一键安装汉化.bat》即可。

2. macOS 用户：
   解压后双击运行《一键安装汉化-macOS.command》即可（脚本已内置 codesign 签名修复）。

3. Linux 用户：
   在解压目录打开终端，执行：bash 一键安装汉化-Linux.sh 即可。

【一键还原官方英文】
随时运行各平台对应的《一键恢复官方英文》脚本，即可毫秒级还原官方原版！
